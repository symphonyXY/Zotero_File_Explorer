# v1.0.0

本地首版日期：2026-11-12。以选定新图标后的程序作为第一个版本。
首版归档标识为 v1.0.0，日期以本地交付记录为准。

## 能力与设计

通过只读 Zotero Local API 同步文献元数据，在本应用 SQLite 索引中搜索；不读写 Zotero 数据库或复制附件库。
支持主/快捷双窗口、分类与多条件检索、多附件、原件/译件识别、人工分类及主附件设置。
提供中英文、深浅主题、全局热键、离线缓存、布局记忆，以及尊重 Windows 动画偏好的有限反馈。
复制与拖放使用真实本地文件 URL、CF_HDROP 和 CopyAction；原件保留。

应用图标采用项目所有者选定的 06-fusion-minimal 源图，生成 PNG 与七档 ICO，统一用于源码与安装器。
README、用户文档、开发专题、贡献/安全指南和 CI 与本版一同组织。

## 扩展边界

后续沿用 core / api / services / storage / platform / ui 分层。
新查询、路径验证和同步保持 worker 执行，Qt 对象只在 GUI 线程更新；身份包含实例、库和条目。
新增界面需保留多选与真实 MIME，新增动画通过 ui/motion.py 的 token/policy 控制。
不得将窗口绘制耗时当作显示 FPS，性能工作按 500 / 5,000 / 20,000 篇合成库记录。
