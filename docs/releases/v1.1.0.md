# 1.1.0 · 文献速览卡

2026-11-18 完成本地 Windows x64 最终交付。相对 1.0.0，个人文献库可以创建、编辑、筛选和复习 Markdown 卡片。
安装沿用原有 AppId 和应用数据目录，Windows 应用列表分别显示产品名与版本号。
“文献库与分类”选中行左侧的蓝色括号状装饰已移除，浅色和深色主题均已验证。

## 卡片与兼容性

每张卡片使用父文献下独立的 Zotero 存储型附件。保存时检查附件身份和正文版本，并回读确认。
草稿位于本应用数据目录。模板扩展点、并发保存和本机接口见 [Zotero 集成](../development/zotero-integration.md)。
在旧索引完成首次刷新前，卡片状态可能显示待确认。使用步骤见[文献速览卡](../user/user-guide.md#文献速览卡)。

## 验证范围

真实文件同步已在 Windows 的两个独立 Zotero 10.0.8 配置上完成，验证过 Koofr 下载件的完整正文。
跨物理设备和 Windows 10 尚待实测。2026-11-18 重新封装本版，安装器和源码包的校验值见交付目录的 SHA256SUMS.txt。
本地安装包、对应源码和校验材料保存在 `releases/v1.1.0/`。
完整压缩包为 `releases/ZoteroFileExplorer-1.1.0-Release-x64.zip`，包含安装器、可直接运行的应用目录、应用源码和 Qt/PySide 对应源码。
源码回归共 149 项通过，Ruff、文档链接和依赖检查通过。安装验收使用独立 AppId，覆盖安装、重装、快捷方式、启动自检与卸载。
Windows 10、跨物理设备同步和生产覆盖升级仍待实测，安装器尚未签名。
