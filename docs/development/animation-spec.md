# 动画与交互规范

## 技术选择

项目实际使用 PySide6 6.10.2 / Qt Widgets / QTreeView，不含 QML 页面。
保留现有布局、信息层次、蓝色强调色、Windows QDrag 和系统文件 MIME。
动画直接使用 Qt Widgets，不引入额外运行时。
QML 会涉及窗口、委托、焦点和原生拖放桥接的全面迁移，当前收益不足以抵消回归风险。

`ui/motion.py` 提供 `MotionTokens`、`MotionPolicy`、`MotionStyle`、`MotionSystem`。
应用窗口通过 `zfeMotion` 属性加入系统；其对话框和菜单继承覆盖范围。

## Tokens 与行为

| 场景 | 基础时长 | 行为 |
|---|---:|---|
| 按下 | 90 ms | 边框/背景反馈；不移动点击区域 |
| Hover / Focus | 150 ms | 控件描边与低强度填充 |
| 菜单进入 | 150 ms | 原生顶层透明度 0.88 → 1 |
| 主窗口进入 | 190 ms | 原生顶层透明度 0.88 → 1；首帧即可输入 |
| 快捷窗口进入 | 120 ms | 适配高频唤出，其余透明度和中断规则保持一致 |
| 对话框进入 | 220 ms | 与窗口一致；不改变模态语义 |
| 附件展开/收起 | 220 ms | Qt 原生 QTreeView，统一 style hint |
| 查询完成/失败回执 | 140 ms | 小范围文字 opacity 0.82 → 1，仅完整动画模式；立即写入真实文字 |
| 退出 | 0 ms | Escape、取消、关闭即时生效 |

默认 OutCubic，无弹跳、缩放、装饰性循环或错峰队列。
速度范围 0.5×–2×。无实际使用场景的 Spring/Stagger 参数没有建立空接口。
减少动画模式使用不超过 70 ms 的基础淡化（再按速度调整），并关闭树高度动画；关闭模式即时反馈。
Windows `SystemParametersInfoW(SPI_GETCLIENTAREAANIMATION)` 为 false 时优先关闭动画。
启动、应用重新激活、保存设置时重新读取系统偏好；非 Windows 或查询失败回退到应用设置。
没有声称支持不可获取的系统辅助功能状态。

## 各界面覆盖

- 主窗口/快捷窗口：进入动画由窗口拥有，Hide/Close 立即停止并恢复 opacity=1。
- 设置、规则、警告/详情对话框：保留原生模态窗口和返回值；按需使用相同淡入。
- 按钮、开关、搜索/筛选输入、下拉框：透明绘制覆盖层，`WA_TransparentForMouseEvents`、NoFocus；
  不消费任何业务输入；高频交互复用动画并从当前数值重定向。
  键盘按下/释放与鼠标共用反馈；相同目标不重新启动，禁用立即归零，未变化的强度不重复申请重绘。
- 文献和导航树：每个视图一个悬停动画，最多同时绘制当前行和上一行的有限明暗过渡，移出或进入空白时仅淡出已有反馈。
  横/纵滚动、按下/拖动、窗口失活、缩放、重置、隐藏立即清除两行反馈；关闭动画时即时切换，选择状态始终可见。
  没有已有反馈的空白区域不启动动画。
  展开使用原生模型索引、行命中和拖放事件，没有为每篇文献创建 QWidget 或动画对象。
- 分类/搜索结果：保留旧数据直到后台结果完成，再一次提交；相同结果不重置模型。
  不对整张表做昂贵截图淡出，也不等待动画才展示数据。保留原来的分页和所有可检索内容。
- 空状态、错误、同步：由真实业务状态更新，不引入假的进度/成功状态；不会以动画遮住错误。
- 主/快捷窗口各有一个 `FeedbackLabel`，共用查询、统计和文件操作回执，成功或失败时有限淡入；连续切换先结束旧过渡并立即写入最新文字。
  保留反馈行与重试入口空间，减少动画/关闭模式直接呈现；隐藏或系统策略变化立即恢复不透明。列表不整体淡化。
- 快捷搜索：自动聚焦；Down 转入结果，Enter 打开当前/首条；新查询未完成时 Enter 不打开旧结果。
  Escape 立即隐藏；置顶重建窗口标志后可正常重新进入。
- 菜单有进入淡化；ToolTip 保留 Qt 原生显示时机、增加统一边框。
  程序没有独立的 Tab、Drawer、Toast 页面系统，因此没有制造无用组件。
- 主题：沿用原色板，明确可见的 Focus/Pressed/Disabled。相同样式不重复应用；
  实际深浅切换仍使用 Qt 样式更新，没有大面积动态模糊或遮挡交互的整窗交叉淡化。
- 拖放：新增随 DPI 缩放的文件数量预览；真实数据仍是本地文件 URL、Preferred DropEffect=1、CopyAction。

## 生命周期与性能约束

动画随控件父对象释放；菜单和设置/规则对话框用完安排 deleteLater。
不存在每条数据一套动画。每个用过的交互控件最多一个反馈层/动画，视图最多一个 hover 动画。
批量恢复展开状态时禁用树动画，避免数百次入场；身份包含 instance/library/document/attachment。
展开、当前行、子附件多选和滚动位置按完整身份恢复，跨库同 key 互不串扰。

`scripts/benchmark.py` 测索引、检索、首屏构建和后台心跳；
`scripts/benchmark_ui.py` 测可见窗口 CPU paint、滚动事件循环、展开、主题、快捷搜索、后台重分类、300 次唤出关闭。
后者不等于显示器呈现帧率；240 Hz 屏幕报告值也不证明应用达到 240 FPS。
`scripts/benchmark_feedback.py --data-dir <新隔离目录> --output <新报告路径>` 专门复验 500 / 5,000 / 20,000 篇的悬停、展开、查询和反复唤出。
分开记录模型填充、CPU paint、事件循环间隔及动画对象数；输入驱动耗时包含在事件循环样本中，单轮对照不代表稳定加速。
本版行为和未测项见[首版说明](../releases/v1.0.0.md)。
真实切换主题等全局操作需单独测量，不能据局部 paint 时间宣称稳定 60 FPS。

## 接口依据

- [Qt QTreeView](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QTreeView.html)：原生树展开、uniformRowHeights 与 Model/View。
- [Windows 动画指南](https://github.com/MicrosoftDocs/win32/blob/docs/desktop-src/uxguide/vis-animations.md)：反馈解释操作、遵守系统偏好并保持输入可用。

## 人工验收

用测试文件（含中文、空格、多附件）验证鼠标/键盘多选、快速反复展开、滚动后拖拽、Ctrl+C 粘贴。
在微信、QQ、Chrome/Edge 上传区测试 Copy、取消、Shift 拖拽、多文件数量与实际路径。
确认源文件未变动。分别切换中英、深浅色、三档动画以及 Windows 动画开关。
关闭后立即再次唤出，确认可见、可输入、无残留动画；用系统工具测实际 Present FPS 和帧时间。
