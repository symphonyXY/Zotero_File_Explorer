# 维护与安全清理

**每项开发、修复、优化或文档任务结束，必须检查并删除已确认无用的文件，同时保存清单。** 不是每条命令后清理。
本规范由根目录 [AGENTS](../../AGENTS.md) 持续引用，不需要定时任务。

## 文件分类

| 类型 | 内容 | 策略 |
|---|---|---|
| 正式项目 | src、tests、assets、config、installer、licenses、scripts、docs、CI | Git 跟踪，禁止自动删除 |
| 开发环境 | .venv、IDE 设置 | 本地忽略，保留环境 |
| 可重建输出 | Python/pytest/Ruff 缓存、build、work | 忽略；仅经验证生成物可删除 |
| 候选交付 | dist 下安装包、源码与第三方源包 | 忽略，保留已有交付，不因可重建而删除 |
| 正式归档 | releases/v版本号 | 本地二进制归档；说明与必要校验元数据可跟踪 |
| 安全备份 | backups、未知文件 | 忽略或报告；用途未确认不删除 |
| 用户运行数据 | LOCALAPPDATA 下本应用数据、Zotero 原始库与附件 | 不进入 Git，不在清理范围 |

## 清理入口

```powershell
.\scripts\clean.ps1            # 默认 Dry Run；只写本地清单
.\scripts\clean.ps1 -DryRun
.\scripts\clean.ps1 -Apply     # 仅删除经验证的标准 CPython 字节码
```

PowerShell 入口调用无额外依赖的 `scripts/clean_project.py`，根路径绑定脚本所在仓库，不接受任意目标路径。
扫描仅限 src/tests/scripts，逐层检查绝对边界、父目录及子项 reparse point，不跟随目录链接。
自动删除仅限：Git 未跟踪且已忽略、对应 Git 跟踪源文件、命名和 magic header 匹配当前解释器、单硬链接的标准 pyc。
其他解释器缓存、pytest 改写字节码、未知文件、跟踪文件、链接均保留并说明原因；保留空目录。

删除前在 `work/cleanup/` 独占创建带时间和随机 ID 的 JSON 清单，记录路径、大小、mtime、SHA-256 并刷盘；
重新检查资格、父路径及文件指纹后逐文件删除，另存 result 清单。失败返回非零，不把保留项伪报删除。
本工具不递归清空目录；旧 `-IncludeRelease` / `-IncludeUninstalledTools` 参数已移除。
不要在构建/测试仍运行时并行清理；正常并发修改会保留变化文件，本工具不是对恶意并发文件系统攻击的隔离机制。

常规任务保留 pytest/Ruff 缓存以加速开发。显式目录整理时，可按独立清单删除已完成测试现场、缓存和经校验的重复构建副本；开发环境、构建工具及唯一正式交付保留。
清理临时实验、资源、测试输出或重复安装器须先证明生成来源、无引用、内容/哈希和替代归档，保存清单后单独操作。
不能只凭扩展名、目录名称、未跟踪状态或 .gitignore 就删除。

普通任务先运行预览，再用 -Apply 删除满足工具条件的字节码。对本任务产生且已确认无用的日志、缓存、模拟数据和构建中间产物，单独列出具体目标、来源、替代物和保留理由；保存含大小/哈希的清单后检查绝对边界、reparse point、硬链接和占用，逐项删除。不要把“已忽略”当成清理完成。
版本重设需要删除旧交付时，先重建并验证替代安装器，保留第三方对应源码，再清理明确的旧版本文件。

## 任务结束清单

1. 修改完成，必要测试已执行，失败与未执行项如实记录。
2. 检查无用文件、实验资源、失效缓存、重复构建输出；不确定项保留。
3. 按变更更新专题文档、UI/动画或发布流程；必要时更新 CHANGELOG 的 Unreleased。
4. 执行文档链接检查和 clean.ps1 预览，然后用 -Apply 清理已验证 pyc；其他已确认无用产物按独立清单删除。无法确认或无法删除的项必须报告原因。
5. 查看 `git status --short`、`git diff --check`、`git ls-files -ci --exclude-standard`，检查误跟踪临时文件。
6. 报告实际删除原因、保留原因、清单路径、测试边界及 Git 状态。保留 .venv 和用户文件；有效历史交付默认保留，明确获准且验证被替代的旧交付除外。
