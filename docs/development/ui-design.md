# UI 设计

现有界面使用 Qt Widgets：标准浏览窗口、快捷搜索窗口、原生设置与规则对话框。
主窗口保持库/分类导航、搜索筛选、文献树、多附件层级与分页；快捷窗口用于快速检索与键盘操作。
沿用蓝色强调色、系统/浅色/深色主题及中英文 catalog，不增加无实际用途的页面体系。

## 视觉层次

主窗口采用独立导航和内容面板，统一圆角、边框、间距及深浅色表面；搜索保留 Ctrl+F 提示，筛选字段有可见标签。
复制作为主操作，刷新为次操作；禁用态保持文字和边界可辨。标题使用适度加粗，表格交替底色减弱，细滚动条保留原生输入行为。
默认显示顺序为标题、作者、年份、类型、状态、文件名、大小、库、DOI；排序和列开关仍按原逻辑列索引。
新配置默认仅显示前五项，已有隐藏列设置（包括全部显示）继续保留；全部元数据可通过“显示列”开启。
主窗口标题列默认使用其余可用宽度，手动调整标题列后停止自动适配，刷新不会覆盖手动列宽。
列宽仍可调整、表头可拖动调整顺序；快捷窗口标题列自适应剩余宽度，状态列按内容取宽。
两窗口隐藏/正常退出时将窗口位置与尺寸、表头状态保存到本应用 settings.json 的 window_layouts；主窗口另存侧栏宽度。
恢复表头后以 hidden_columns 为列可见性的权威设置，排序条件不随布局恢复。无效的可选布局忽略，不影响启动。
“显示列 → 恢复默认布局”恢复主窗口尺寸、侧栏、列序、列宽和默认可见列，保留当前选择、展开与查询条件。
导航与工具使用 `ui/theme.py` 生成并缓存的原创描边图标（1x/2x），没有按行创建控件，也无额外图片或运行时依赖。
应用图标统一使用 assets/icons/app.ico，源图与生成说明见[图标资源](../../assets/icons/README.md)。较长导航文案可通过提示或调整侧栏宽度阅读；主内容区域保持不可折叠。

## 交互契约

- 主窗口每页 500，快捷窗口最多 200；显示范围不代表降低全库检索规模。
- 选择、当前行、展开与滚动在刷新后按稳定身份恢复。相同结果不重置模型。
- 主窗口和快捷窗口共用查询状态：输入变化立即使旧查询失效，防抖、查询中及失败期间保留旧列表，但禁用文件操作和分页。
- 查询状态显示真实等待、完成数量或失败提示；失败提供原条件重试，保留输入。索引减少后自动回到有效页。
- 查询状态和文献/选择统计合并到一个固定底部区域；正常时仅显示统计，查询中/失败时明确标注保留的上次结果。
  复制校验与结果在发起操作的窗口就地显示，成功保留 8 秒，失败保留至后续操作覆盖；期间查询和选择变化不吞掉回执。
  异步校验期间因语言变化重建窗口时，回执转到对应的新窗口；窗口隐藏不阻止实际复制完成。
- 主窗口分页查询期间阻止连续累加页码，仍为每页 500；快捷窗口最多 200。
- Down 进入结果，Enter 打开当前/首条；查询未完成或失败时不得误开旧结果。中文输入法组合期间不拦截提交键。
- 初次使用、无结果和空列表查询失败提示居中显示；提示透明于鼠标输入，不改变行命中区域。
- 复制、打开和定位按钮依据当前查询及所选附件元数据启用，实际文件验证仍在 worker。搜索、年份、标签、库、类型、导航与结果列表有中英文可访问名称。
- Escape 立即隐藏快捷窗口，退出不等待装饰动画。
- QDrag 使用本地文件 URL、Windows CF_HDROP 和 CopyAction；预览只是装饰，不代替真实文件数据。
- 主题、焦点、按下、禁用和选中状态必须清晰，反馈层不能拦截鼠标或改变拖放命中区域。

详细动效仅在[动画规范](animation-spec.md)维护。视图调整须按[测试规范](testing.md)验证 MIME、多选与实例/库身份。
