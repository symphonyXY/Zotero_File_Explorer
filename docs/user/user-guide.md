# 使用说明

## 连接和浏览

1. 安装 releases/v1.0.0 中的 Setup-x64.exe，从开始菜单打开 Zotero File Explorer。
2. 启动 Zotero，在设置 → 高级开启允许本机其他应用通信。软件默认只连接 `127.0.0.1:23119/api/`。
3. 点击“立即同步”。连接信息只有同步真正成功后才显示“已同步”。403 时按提示开启开关；断线时展示最近缓存。
4. “全部文献”显示有确认原件的父文献和独立附件。左侧个人/群组库下保留各自分类层级，同名分类按库区分；“未分类”不包含加入其他分类的文献。父分类只显示直接归属，不自动包含所有子分类。
5. 展开行查看全部 Original 附件；Translated 独立可查，Review 在待确认列表。没有缓存时显示首次连接提示，没有演示数据。

标题、作者、年份、DOI、标签、真实文件名均可检索，空格分隔的词同时匹配，忽略大小写与英文重音。筛选可叠加：库、分类、文件类型、年份、精确标签、可用原件。每页 500 篇，上一页/下一页浏览。表头排序；右下角“显示列”选择列。文件名与附件标题独立保存。

## 打开、复制、拖拽

双击文献打开主附件，双击子行打开相应文件。默认主附件：用户指定 → 原始 PDF → 其他原始支持类型；同级按归一化文件名和 Key 稳定排序。右键原始子附件可设为主附件。

选中行，Ctrl+C 或“复制文件”，再到资源管理器 Ctrl+V。右键“复制文件路径”“复制文件名”只复制对应文字，与文件复制不同。Ctrl/Shift 支持多选；同路径不会重复传递。部分失效时只复制仍可用的文件，全失效则提示。

按住文献行拖到接收文件的目标，传递主附件；拖动展开子行传递该附件。只提供复制动作，原文件保留。网页和聊天软件是否接收取决于目标版本、权限及上传控件；参见测试矩阵。无法拖入时，使用复制真实文件、定位到资源管理器后选择上传、复制路径到文件选择框等备用方式。不会自动发送聊天消息或绕过网页限制。

## 纠正翻译识别

在“待确认附件”展开文件，右键可查看真实文件名、路径、原因，标记 Original/Translated，或清除该附件的手动分类重新识别。手动结果保存在本软件目录，不改变 Zotero 附件。翻译列表也支持同样纠正。

“翻译过滤规则”中可添加、直接编辑、禁用、删除通配符规则。模式支持 `*`/`?`，字段可选文件名或标题，结果可选 Original/Translated/Review；按表中顺序采用第一条匹配。可输入测试文件名和标题预览匹配。恢复默认清空自定义规则；内置保守产物识别保留。需要保留某类后缀时可增加 Original 规则或逐件手动确认。没有任何过滤操作会删除文件。

## 快捷窗口和系统设置

Ctrl+Alt+Z 或托盘“快捷窗口”打开紧凑搜索，最多显示前 200 条；可继续输入收窄。复制、拖拽之后窗口保持打开。右上角可取消置顶，Escape 隐藏。开始菜单有独立快捷窗口入口。快捷键被占用时明确提示，在设置中换成 Ctrl/Alt/Shift + 字母、数字或 F 键。

设置提供中英文、系统/浅色/深色、轮询间隔（默认 60 秒，最少 15 秒）、本机 API、数据目录自动检测/手动选择、链接基础目录、关闭到托盘、开机启动。开机启动默认关闭，只在主动保存选项后写入当前用户 Run 配置。Ctrl+Q 或托盘“退出”完全退出。语言保存后立即重建两窗口文字。

## 离线与故障排查

- Zotero 关闭后仍可搜索最近元数据和分类，打开/复制/拖拽仍在磁盘的文件。首次无缓存时需先连接一次。
- 文件缺失或未下载：先在 Zotero 下载附件；回到软件点击同步。外部文件移动后，右键“重新定位文件”可保存仅本软件使用的路径映射。
- 数据目录变化：在设置中重新检测/选择目录，再立即同步。文件路径仍以 API 返回结果优先。
- 403：开启本机通信。404：附件路径未找到或 API 能力不足，记录仍保留。412：实例变更，本次事务终止并重新探测。频繁编辑导致版本变化时会稍后重试。
- 索引异常：软件会保留损坏库并重建；也可手动“重建本软件索引”。手动确认与路径映射保留。同路径替换 Zotero 数据库后请主动重建本应用索引。
- 日志位于 `%LOCALAPPDATA%\ZoteroFileExplorer\logs\errors.log`，只记录错误类别与状态码，限制 1 MB × 4，不记录论文正文或完整路径。
- 完全卸载：用 Windows 应用列表或卸载程序。运行时索引和设置默认保留，可自行备份后删除 `%LOCALAPPDATA%\ZoteroFileExplorer`；不要删除 Zotero 目录。

## 动画与键盘

主窗口默认优先显示标题、作者、年份、类型和状态；已有列设置会保留。其余信息可从“显示列”开启，表头可拖动调整顺序。
标题列默认随窗口宽度适配，手动调整后保留该宽度。两窗口隐藏或正常退出时记住尺寸和位置，主窗口另记住侧栏及列宽。
使用“显示列 → 恢复默认布局”可恢复主窗口的默认尺寸和列布局，当前选择及筛选条件会保留。
复制文件时，校验中、成功或失败提示显示在发起操作的窗口底部；成功提示约 8 秒后恢复统计，失败可在处理文件问题后重试。

设置中可选完整动画、减少动画或关闭非必要动画，并调节速度。Windows 关闭动画时应用会尊重该设置；应用重新激活时刷新系统偏好。关闭动画不影响选中、拖放或文件操作。快捷搜索可用 Down 进入结果、Enter 打开、Escape 关闭；查询仍在处理或失败时，搜索框 Enter 不会打开上一批结果。
