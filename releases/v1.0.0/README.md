# Zotero File Explorer 1.0.0

从托盘退出 Explorer，运行 `ZoteroFileExplorer-1.0.0-Setup-x64.exe` 安装。也可直接启动 `app/ZoteroFileExplorer/ZoteroFileExplorer.exe`。

用户指南位于 app/ZoteroFileExplorer/docs/user。source 包含本版应用的生产源码和构建说明。ThirdPartySources 保存 Qt 与 PySide 对应源码，再分发时请一并保留。SHA256SUMS.txt 记录逐文件校验值。

2026-11-18 重新封装。应用程序与运行库沿用本版原始二进制。
